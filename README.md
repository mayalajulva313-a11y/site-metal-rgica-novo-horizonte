# Metalúrgica Horizonte

Site institucional estático da Metalúrgica Horizonte Ltda., empresa fictícia. O projeto usa HTML e um único arquivo CSS, sem etapa de build.

## GitHub Codespaces

Crie um repositório GitHub público com README, abra o repositório e escolha **Code → Codespaces → Create codespace on main**. Os arquivos deste site ficam na raiz do projeto.

## Publicar na Netlify

1. Envie os arquivos para o repositório GitHub.
2. Na Netlify, escolha **Add new site** e conecte esse repositório.
3. Deixe o comando de build vazio e informe `.` como diretório de publicação.
4. Publique o site. Os pushes seguintes para o repositório conectado atualizam a publicação.

`index.html` é a página inicial. As outras páginas são `servicos.html` e `contato.html`. O histórico de uso da IA está em `uso-da-ia.md`.
